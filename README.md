# 汇流 FlowDisk

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**v0.5 预览版**：OneDrive / Google Drive 已实现协议接入与模拟验证，真实账号登录和下载尚待验证。完整支持范围见下表。

Rust 下载引擎、中文 Web 工作台、Docker Compose。连接网盘后，浏览和管理已存内容，解析分享链接、预览并选择文件后下载，支持多连接分段、断点续传、目录递归下载和本地文件管理。

**登录不使用远程桌面、截图、鼠标转发或浏览器容器。** 夸克短信登录在用户浏览器里加载官方表单，迅雷短信登录直接在工作台填写并调用官方接口；二维码由 Rust 从官方接口取得或在本地生成；Cookie 和令牌仅在服务端交换及保存。百度扫码账号的文件浏览、分享转存和原文件取链，以及迅雷分享转存，由 Rust 直接接入；其他文件驱动及百度 OAuth 账号通过独立的 OpenList v4.2.6，下载队列和认证协调由 Rust 实现。

## 启动

需要 Docker Engine、Docker Compose v2；初始化脚本需要 POSIX shell 和 openssl。支持 Linux，也可在 macOS 的 Docker Desktop 中使用。

```sh
git clone https://github.com/HosisoraLing/flowdisk.git
cd flowdisk
chmod +x setup.sh
./setup.sh
docker compose up -d --build
```

首次编译需要下载 Rust 依赖。构建使用 `Cargo.lock` 和 `--locked`。

1. 打开 <http://127.0.0.1:8080>，输入 `.env` 中的 `APP_TOKEN` 进入工作台。
2. 点击网盘卡片或“网盘账号”连接账号，登录成功后自动建立挂载。
3. 粘贴分享链接并点击“解析分享”；未登录时先连接账号。需要转存的分享先显示容量和预计占用，确认转存后浏览内容、预览并勾选，点击“下载所选”才会创建任务。也可直接在网盘文件里选择下载。
4. “下载任务”按分享、文件夹或批次分组，可折叠并保留状态；可暂停、继续、查看实时/峰值/平均速度、Steam 风格曲线和预计完成时间；“本地文件”中保存到设备、重命名或删除已完成文件。

`.env` 含访问凭据，权限为 600。默认服务仅监听本机。局域网访问时设置 `BIND_IP` 为服务器的局域网地址并重建容器；通过公网访问时请配置 HTTPS、`COOKIE_SECURE=true` 和访问控制。OpenList 管理端口仍只绑定本机。

### 分享浏览与选择（v0.4）

桌面界面提供目录树、逐文件大小、文件夹汇总大小、名称搜索和类型筛选；勾选范围跨文件夹保留，所选文件数及总大小自动去重计算。图片、音频、视频和文本从已授权网盘按需预览，不创建下载任务；已完成文件优先复用本地副本。浏览器不能解码的媒体可下载原文件；文本最多显示前 256 KiB，HTML/SVG 作为纯文本处理。

需要保存副本时先递归计算整个分享的大小，显示网盘总量、已用、可用、预计占用和转存后预计剩余。空间不足时停止转存并提供管理文件及重新检查入口；容量未知时明确显示，不伪造数值。115 分享挂载、OneDrive / Google 的只读分享视图无需转存，不显示此确认步骤。容量是操作时的估算，云端去重及其他并发操作可能改变最终数值。

疑似广告根据名称中的推广用语、小体积网址或快捷方式等简单规则标记，不自动删除。所选范围包含这些内容时先提示，可一键取消选择或明确保留下载。规则可能误判，不读取文本内容判断广告。

从包含“解压密码/压缩密码/解压码”的文件夹名和空文件名提取密码，按最近目录范围附加到压缩包备注，支持复制；多个同级提示会保留，不改动原文件名。备注随下载任务和本地文件列表保留。

分享、目录或批量下载的分组标识持久化到任务记录；桌面展开/折叠状态保留在当前浏览器。旧分享任务会自动归入对应分享组。

| OneDrive | 官方 OAuth（自建应用已配置时直接跳转）；默认提供 OpenList 授权助手入口及刷新令牌导入，支持自建应用令牌 | Microsoft Graph 读取个人 OneDrive、国际版组织账号及有权访问的 SharePoint 分享；文件/文件夹均可读取，无需复制到本人网盘 |
| Google Drive | 官方 OAuth（自建应用已配置时直接跳转）；默认提供 OpenList 授权助手入口及刷新令牌导入，支持自建应用令牌 | 读取 `file/d/…`、`drive/folders/…`、`open?id=…`、`uc?id=…`，支持 resourcekey、分页和普通文件下载，无需转存 |

界面按真实能力显示登录方式，未把所有网盘统一短信登录标记为已完成。分享失效、提取码错误、网盘空间不足或安全验证会显示具体失败提示并保留任务供重试；不会后台反复发送短信，也不会自动破解安全验证。

夸克短信表单需要浏览器能访问 `uop.quark.cn` 及其官方验证资源；浏览器隐私设置或网络阻止第三方表单时，切换扫码。短信与扫码的最终可用性仍受官方接口和风控影响。

百度默认扫码无需配置。若希望使用自建应用的官方 OAuth，可在 `.env` 配置以下内容，并重建下载器容器：

```dotenv
BAIDU_CLIENT_ID=你的百度网盘应用ID
BAIDU_CLIENT_SECRET=你的百度网盘应用密钥
PUBLIC_URL=https://你的工作台域名
```

在百度应用中登记回调地址 `PUBLIC_URL/oauth/baidu/callback`，并确认开通网盘权限。回调只接收随机会话 state 和授权码；令牌在服务端交换，不出现在前端或跳转地址。未配置时显示“扫码登录”“导入 Cookie”和“已有授权”；默认使用扫码。

OpenList 高级管理入口为 <http://127.0.0.1:5244>，账号 `admin`，密码为 `.env` 中 `OPENLIST_PASSWORD`。已有挂载会根据驱动识别；连接新的账号使用 `/baidu`、`/quark`、`/115`、`/thunder`、`/onedrive`、`/google`。同一服务面向一个可信用户，不是多用户账号隔离系统。退出账号会移除对应网盘及本应用建立的分享挂载；有活动下载时须先暂停。更换已有挂载账号时同样需暂停活动任务。

### OneDrive 与 Google Drive

在“网盘账号”选择对应网盘 → “官方授权”。尚未配置自己的应用时，点击 OpenList 授权助手，在官方账号页登录，取得刷新令牌后回到工作台“已有授权”导入，授权来源选择“OpenList 默认应用”。此模式的授权及令牌刷新经过 OpenList 服务；按其[OneDrive](https://doc.oplist.org/guide/drivers/onedrive) / [Google Drive](https://doc.oplist.org/guide/drivers/google_drive) 文档操作。不会伪装成短信或扫码接口，也不使用远程桌面。

自建应用直接授权：设置 `PUBLIC_URL=https://你的工作台域名`；Microsoft 应用填写 `ONEDRIVE_CLIENT_ID`、`ONEDRIVE_CLIENT_SECRET`，Google Web 应用填写 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`。在各自应用登记精确的回调地址：

- Microsoft：`PUBLIC_URL/oauth/onedrive/callback`；支持组织及个人账号，授权委托权限 `Files.ReadWrite.All` 和 `offline_access`，以便管理本人文件并读取被分享项目。
- Google：`PUBLIC_URL/oauth/google/callback`；启用 Google Drive API，配置同意屏幕和测试用户，授权范围 `https://www.googleapis.com/auth/drive`（浏览及增删改需要）。测试模式令牌期限和管理员政策仍适用。

重建下载器容器后生效。采用随机会话 state 与 PKCE，授权码在后端兑换，原始令牌和客户端密钥不返回浏览器。普通局域网 HTTP 地址不能作为 Google Web OAuth 的注册回调；可先使用授权助手。已有自建应用令牌也能直接导入，选择“我的自建应用”，填写对应客户端信息；OneDrive 还要填写当时的原授权回调。

分享读取为只读视图，不转存、不消耗额外云端容量；本人网盘的上传、新建、重命名、移动和删除仍由对应 OpenList 驱动执行。分享中重名条目仅在虚拟路径中增加文件 ID 用于区分，不改云端名称。预览、选择范围、广告提醒、密码备注、分组、速度图、预计时间、多线程及本地断点续传使用原有流程。Google 原生在线文档和快捷方式目前需先在官方页面导出为普通文件；不把空元数据当作已下载文档。需要密码、组织额外验证或管理员拒绝访问的分享会提示失败；当前 OneDrive 接入为国际版，不包含世纪互联/政府版。

部署服务器及 OpenList 容器必须能访问微软、Google 和相应下载地址。网络受限时使用容器可访问的代理：设置 `CLOUD_HTTPS_PROXY=http://宿主机局域网地址:代理端口` 和可选 `CLOUD_HTTP_PROXY`，代理监听应允许容器访问；不要填容器内 `127.0.0.1`。`CLOUD_NO_PROXY` 默认跳过 OpenList 内网请求。只改变上游访问路径，不承诺突破账号限流。

真实账号授权和真实分享下载需本人完成登录后验证；本版本的自动化结果不替代这一步。

### 百度扫码接入

点击“百度网盘” → 使用百度网盘 App 扫码 → 在手机确认。Rust 通过官方 passport 二维码接口交换本人 Cookie，再读取登录状态和根目录验证可用性，成功后将账号保存到 `data/flowdisk/baidu.json`（权限 600）。退出百度账号会删除该文件。原始 Cookie、BDUSS、STOKEN 和下载签名不会返回前端或写入下载记录。

百度扫码账号固定使用 `/baidu`。如同一路径已有 OAuth/OpenList 账号，请先在“网盘账号”退出原账号，再切换登录方式；切换有活动下载的账号会被拒绝。账号验证失败会保留原有连接。

粘贴标准 `https://pan.baidu.com/s/1...` 分享，支持链接中的 `pwd` 和粘贴文字中的提取码。转存使用任务独立目录、拒绝覆盖已有同名文件；重试复用已经保存的同名条目，异步转存或内容未齐时提示等待重试。需要安全验证时提示在官方网盘处理，不自动解验证。

原文件取链使用本人的 Cookie、官方文件元数据接口和 HTTPS 官方下载域名；仍由现有 Rust 分段引擎处理续传与校验，每文件连接数根据账号等级和部署配置选择。不会把在线播放地址作为原文件下载。接口可能因账号权限、网盘风控或上游变化拒绝取链，不能承诺突破账号限速。百度分享暂不支持非标准短链、旧版 `share/link` 形式或分享内指定子目录。

### 文件管理

网盘文件支持上传、新建文件夹、重命名、同网盘移动、删除、批量选择和文件夹递归下载。删除前有确认，涉及未完成任务时会提示先移除任务；不能改名网盘根目录、路径穿越、跨盘移动或移动到自身子目录。移动由 OpenList 异步执行，界面会提示已提交，完成后刷新目录。

“本地文件”扫描实际下载目录，移除历史记录后仍能发现文件；可以重命名、保存到设备和删除。活动下载禁止改名、删除，符号链接不纳入文件列表。删除本地文件不会删除网盘原文件，删除网盘文件不会自动删除本地副本。

### 下载保存到哪里

- 最终文件：`./downloads/<任务 UUID>/<文件名>`。用独立任务目录避免同名文件覆盖。
- 暂存分段、任务记录：`./data/flowdisk/`；网盘授权：`./data/openlist/`。
- 合并时需要额外磁盘空间，建议预留最大活动文件总大小的 **2 倍**。失败或暂停会保留分段以供续传。
- 点击“保存到设备”从服务器流式读取已完成文件；此步骤的速度取决于服务器到设备的带宽。
- 移除未完成任务会清理其暂存文件；移除已完成任务只移除记录，保留服务器上的成品文件。移除记录后仍可在“本地文件”中管理成品。
- 容器重启后，未完成任务显示为“已暂停”，点击“继续”恢复；不会在重启后自动发起网盘访问。

### 远程服务器

默认只绑定回环地址。在电脑执行 SSH 转发，可使用远端服务而不公开端口：

```sh
ssh -L 8080:127.0.0.1:8080 -L 5244:127.0.0.1:5244 user@server
```

要对局域网提供 FlowDisk，在 `.env` 设置 `BIND_IP=0.0.0.0` 后重建容器。HTTPS 反向代理下设置 `COOKIE_SECURE=true`。OpenList 配置端口仍只绑定回环地址。使用 HTTPS 或 SSH 隧道传输真实凭据。改过 OpenList 管理员密码后，同步更新 `.env` 中 `OPENLIST_PASSWORD` 并重建下载器容器。

Linux 上容器使用初始化时记录的宿主 UID/GID，目录由脚本创建。如果迁移数据或用另一个用户部署，请调整 `.env` 的 `PUID`、`PGID` 与数据目录所有权。不要让其他程序修改活动任务的分段文件。

## 怎样提高速度

下载器会先用 `Range: bytes=0-0` 探测分段能力，然后以默认 **8 MiB** 分段、每文件默认 **8 个并发连接**下载。大于约 80 GiB 的文件自动增大片长，使分段数量不超过 10,000。连接复用，每连接使用 1 MiB 缓冲将小块网络数据合并写盘，内存不随整个文件大小增长。

- 真正支持 Range 才并发；返回 `200` 的服务器自动退回单连接。
- 每段严格验证 `206`、`Content-Range`、响应长度与可用的 ETag / Last-Modified，拒绝把整文件误当分段拼接。
- 分段断流后先保存已写入内容，再从该字节重试；连续四次没有明确进展时停止当前轮。有进展可继续恢复，每个磁盘分段最多 512 次请求；退避并处理秒数形式的 `Retry-After`。
- 失败后重新获取下载链接，任务最多三轮尝试，逐轮减少并发。鉴权失败会提前结束当前轮，触发重新取链。
- 继续下载前比较文件大小、修改时间、网盘 hash 信息及 HTTP 校验标记；变化时清理旧分段。
- 合并后检查总长度并计算 SHA-256，写入完成后才标记成功。SHA-256 用于本地产物校验，**不是**与网盘原始哈希比对；没有远端校验标记时，无法识别所有“同长度同时间”的远端变化。

在 `.env` 调节后执行 `docker compose up -d --force-recreate downloader`：

| 参数 | 默认 | 范围 | 用途 |
| --- | --- | --- | --- |
| `CONNECTIONS_PER_FILE` | 8 | 1–32 | 单文件分段并发上限，直接取链时采用驱动返回的更低限制；代理路径需按实际情况调低 |
| `BAIDU_CONNECTIONS` | 空（自动） | 1–16 | 按实际会员等级自动选择；普通账号默认 1，百度单账号同一时间下载一个文件 |
| `ACTIVE_DOWNLOADS` | 2 | 1–8 | 同时运行的下载任务数 |
| `GLOBAL_CONNECTIONS` | 24 | 1–64 | 所有任务共用的 HTTP 连接上限（含探测） |

建议从 4–8 个连接开始；观察实际吞吐量再加到 16。遇到 429、频繁失败或吞吐下降时减少并发。多连接能够改善单连接吞吐与网络利用率，**不能保证突破账号总限速、会员限制、风控、地区或带宽限制**。尤其百度的非会员接口速度可能很低；夸克的代理路径还受 OpenList 宿主网络和性能约束。没有使用付费解析站、共享会员凭据或提权接口。

## 验证与开发

Rust 1.88+；网盘下载核心不需要 Node.js、数据库或 Redis；普通链接和 BT 由 Docker 中独立的 aria2 处理。开发机没有 aria2 时仍可使用网盘功能。

按改动选择必要检查，集中完成后统一运行，不必每一步重复。

```sh
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
cargo build --locked
python3 tests/integration.py target/debug/flowdisk
python3 tests/control.py target/debug/flowdisk
```

集成测试只使用 Python 标准库，在随机本地端口启动模拟网关与 CDN，使用临时目录，不需要真实账号。覆盖并发原样下载、断流、过期链接、限流、单连接回退、空文件、暂停、进程重启、源文件变化、不合法分段响应与鉴权；control.py 补充登录、分享恢复、文件管理、错误授权回滚和 OAuth state 检查。可选测速：`cargo build --release --locked && python3 tests/benchmark.py target/release/flowdisk`。测速脚本比较 128 MiB 文件的 1/8 连接，分别三轮取中位数；**是受控本地实验，不是网盘速度承诺**。

真实 OpenList v4.2.6 的本地存储挂载已用于 API / 代理 / 下载链路验证。2026-10-18 补充夸克普通账号实测：552.7 MiB 文件完成下载，重启续传、文件大小、独立 SHA-256 和 ZIP CRC 校验通过；全程平均约 0.66 MiB/s。百度已实际完成扫码、目录读取、小文件下载和云端文件增删改查；百度大文件已发现并修复分段大小、UA 绑定和断流恢复问题，75.4 MiB 文件已完整续传，并通过远端 MD5 与独立 SHA-256 校验；持续高速仍未证实。迅雷真实短信登录及目录读取已通过；115 与修正后的迅雷扫码仍待本人确认实测。详情见 [VALIDATION.md](VALIDATION.md)。

本地启动时设置 `APP_TOKEN`、`OPENLIST_PASSWORD`、`OPENLIST_URL`（默认 `http://openlist:5244`）；可选 `BIND`（默认 `0.0.0.0:8080`）、`DATA_DIR`（默认 `data`）、`DOWNLOAD_DIR`（默认 `downloads`）。请只运行一个实例使用同一数据目录；该版本不是多用户系统。

## 保留的边界

不含磁力离线任务或跨盘搬运；预览仅播放浏览器支持的格式，不提供转码。一次递归下载最多 1000 个文件、5000 个目录和文件节点；超过时请拆分目录。最多保留 500 个分享任务、1000 条下载记录。非 Range 来源暂停后将重新开始该文件。网盘设置了额外目录密码时，请改用已获权限的独立挂载，本版界面不输入目录密码。

OpenList 驱动依赖上游接口；接口变动可能需要升级独立 OpenList 容器。Compose 固定 v4.2.6，升级前备份数据并验证账号；应用本身不会自动升级驱动。登录会话仅保存在内存，重启后需重新开始未完成的登录；分享和下载记录会保留。

## 速度、网页续传与文件管理（v0.3）

- 每个下载任务显示实时、峰值、平均速度、Steam 风格深色填充曲线、剩余时间与预计完成时刻。平均速度按实际收到的文件数据 / 活跃时间计算，排除排队及暂停；网络重试的传输量计入统计，包含取链、等待和合并期间的活跃时间。峰值来自采样区间。曲线保留最近 180 个采样，统计随任务保存；每 5 秒及结束时落盘，突然断电可能丢失最后 5 秒统计，不影响已保存文件分段。升级前旧任务显示“暂无统计”，不会编造历史速度。
- 预计时间用近期速度估算，会随网络变化；暂停/排队时显示相应状态，收尾时显示合并与校验。
- 已完成文件在“下载任务”或“本地文件”点击“保存到设备”。服务提供 `Accept-Ranges`、`206 Content-Range`、ETag / If-Range 和 HEAD，支持浏览器、下载工具的断点续传。服务器从网盘下载和用户从网页下载是两段独立传输；浏览器是否保存未完成文件、提供“继续”按钮取决于浏览器自身。
- 网盘管理支持上传文件、新建文件夹、分页浏览、当前页按名称筛选、重命名、移动和删除。网页单次上传最多 64 MiB，拒绝覆盖同名内容；更大上传可用官方网盘客户端。百度使用原生 Rust 上传接口，其他网盘经 OpenList 转发，具体能力由驱动和账号权限决定。
- 百度每次 Range 请求最多 4 MiB，保留旧磁盘分段继续下载。优先官方 PCS Locate，失败回退 filemetas，并保持对应 UA；自动读取会员状态，普通账号 1 连接、VIP 4、SVIP 8，同一百度账号只同时下载一个文件。可在容器环境变量设置 `BAIDU_CONNECTIONS=1..16` 覆盖；增加线程不保证提速。

GitHub 开源实现与速度实测边界见 [百度下载调研](docs/baidu-research.md)。

## 迅雷手机验证码与扫码（v0.3.1）

点击“迅雷云盘”默认显示手机号和验证码表单。输入中国大陆 11 位手机号，点击“获取验证码”，填写短信后点击“登录迅雷云盘”。打开登录弹窗不会自动发送短信；同一手机号跨会话 60 秒内限制重复发送。需要安全验证时，仅展示迅雷官方验证页面或链接，由本人完成，不自动求解。手机号、短信编号、验证码和安全凭据不会写入任务记录；成功后仅把刷新授权交给网关保存。

扫码继续支持迅雷 App，已修正官方 Android 客户端默认地址指向不存在的 `/__/auth/device/` 所造成的 404；现在转至官方账号中心确认页。二维码生成与网页返回 200 不等于本人已扫码成功，真实短信收取、短信登录及网盘目录读取已由本人和服务端共同验证；修正后的手机扫码确认仍待实测。

短信动作接口：`POST /api/logins/{id}/action`，发送为 `{ "action": "send", "phone": "11位手机号" }`，验证为 `{ "action": "verify", "code": "短信验证码" }`。登录会话只在内存保存，取消或到期后失效。

## 分享选择接口（v0.4）

- `POST /api/shares`：提交分享，检查登录并读取转存估算，**不会创建下载任务**。
- `GET /api/shares/{id}/contents`：当前状态、容量估算及已准备的目录内容，包括路径、大小、广告原因和密码备注。
- `POST /api/shares/{id}/prepare`：明确确认需要的云端转存。容量未知时需要 `{"allow_unknown_capacity":true}`，已知不足时拒绝。
- `POST /api/shares/{id}/download`：提交 `{"paths":["分享内完整路径"]}`；疑似广告需显式 `allow_ads:true`。仅下载准备时记录的选中文件，归入同一分享组。
- `GET/HEAD /api/shares/{id}/preview?path=...`：仅允许此分享的已准备文件；`GET/HEAD /api/preview?path=...` 用于已存网盘文件预览。接口经过工作台认证，不向浏览器暴露网盘下载凭据。

桌面示例：[分享内容](docs/share-desktop.png)、[转存容量](docs/share-capacity.png)、[分组任务](docs/download-groups.png)。示例均使用虚构文件。

## SMB 网络共享

在“网盘文件 → 连接 SMB”填写连接名、服务器 IP/域名、端口（默认 445）、共享名称和用户名/密码，可指定共享内根目录。连接会先验证，失败时保留原配置；支持多个共享。密码仅提交至后端并由 OpenList 保存，不返回浏览器。文件浏览、预览、上传、改名、移动、删除和下载沿用网盘流程，操作能力受共享权限限制。更换或断开有活动下载的连接前先暂停任务。

## 普通链接下载

“链接下载”可批量添加 HTTP、HTTPS、FTP 地址；SFTP 仅在 aria2 编译支持时显示。可为需授权的链接提供 User-Agent、Referer、Authorization、Cookie 请求头，不支持在 URL 中填写账号密码。任务按批次进入统一下载列表，可暂停/继续；已完成文件支持网页保存和 Range 续传，也显示在本地文件列表。aria2 RPC 只监听容器内回环地址，不开放管理端口。
